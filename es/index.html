Añade GET /pulsar

Una ruta comprueba tu base de datos, caché, workers y proveedores, y devuelve un JSON pequeño. Guías para 12 frameworks, o escríbela a mano en cualquier lenguaje.

app.get("/pulsar", async (req, res) => {
  if (!authorized(req)) return res.sendStatus(401);
  res.set("Cache-Control", "no-store").json({
    status: "operational",
    components: [{ name: "PostgreSQL",
      state: await checkDatabase(), uptime30d: 0.9999 }],
    checkedAt: new Date().toISOString(),
  });
});

Protégelo con un token

Un PULSAR_TOKEN largo y aleatorio vive en el entorno de tu servidor y solo viaja en la cabecera Authorization. Token incorrecto: sin comprobaciones, 401.

PULSAR_ENABLED=true
PULSAR_TOKEN=<openssl rand -hex 32>

Estado en tiempo real

Estado global, cada componente, tiempo de respuesta y uptime de 30 días de un vistazo.

Solo lo que cambia

Degradaciones, caídas y recuperaciones; nunca una notificación por cada comprobación.

Errores claros

Tiempo agotado, TLS, token incorrecto, payload no válido: Pulsar dice por qué y conserva el último estado.

Estadísticas

Disponibilidad, percentiles de latencia y periodos con problemas de 24 horas o 7 días.

Herramientas

Validador de payload, fragmentos, generador de tokens, calculadora de SLA, prueba de latencia, inspector TLS e informes.

Bloqueo de la app

Face ID, huella o código. Los tokens nunca salen del Llavero ni del Keystore.

Cuando falla, Pulsar te dice por qué.

Nada de un punto rojo y encogerse de hombros. Cada comprobación fallida se explica con palabras claras, y el último estado conocido de cada componente sigue en pantalla.

Error de autenticación
Tu API rechazó el token de Pulsar.
Tiempo de espera agotado
Sin respuesta completa de api.example.com en 10 s.
Falló el handshake TLS
No se pudo verificar el certificado del servidor de api.example.com.
Redirección insegura bloqueada
El servidor redirigió de HTTPS a HTTP sin cifrar. Pulsar nunca envía tu token por HTTP sin cifrar tras una redirección.
Host no encontrado
Falló la búsqueda DNS de api.example.com.
Respuesta de Pulsar no válida
Cada error de validación indica el campo y lo que se esperaba.

Pensada para el momento en que algo falla.

Siete herramientas, todas en tu móvil.

Pequeñas utilidades para los momentos alrededor de un incidente. Todo se ejecuta en local; los tokens se leen del almacenamiento seguro solo cuando una herramienta envía una petición.

  1. Validador de payloadPega una respuesta y compruébala contra el protocolo, campo a campo.
  2. Fragmentos de solicitudcurl, HTTPie, fetch, Python y una comprobación para GitHub Actions, con $PULSAR_TOKEN y nunca tu token.
  3. Generador de tokensTokens de 256 bits y la línea .env correspondiente.
  4. Calculadora de SLATiempo de caída permitido por 99,9 %, 99,99 % y cualquier objetivo que escribas.
  5. Prueba de latenciaPeticiones secuenciales con p50, p95 y jitter.
  6. Inspector TLSEmisor del certificado, caducidad y días restantes de cualquier host.
  7. Informe de incidentesUn resumen en Markdown de los incidentes de un proyecto, listo para un postmortem.

Seguridad que no tienes que configurar.

Los valores por defecto son los seguros, y ninguno se puede desactivar.

Tokens sellados

Guardados solo en el Llavero de iOS o el Android Keystore; no se vuelven a mostrar ni se escriben en registros, exportaciones o notificaciones.

TLS siempre validado

Los certificados autofirmados o que no coinciden se rechazan. No existe un botón de «confiar igualmente».

Sin fugas en redirecciones

Se bloquean las redirecciones de HTTPS a HTTP y el token nunca se reenvía a otro host.

HTTP solo donde toca

HTTP sin cifrar solo se permite para servidores de desarrollo en tu red local, y siempre aparece como No seguro.

Bloqueo de la app

Face ID, huella o el código de tu dispositivo, tras el tiempo que elijas.

Nada sale de tu móvil

Sin cuenta, sin servidores, sin analítica. Los detalles, en la Política de privacidad.

Tus proyectos, tokens e historial se quedan en tu móvil. Pulsar no tiene servidores a los que enviarlos.

  • Sin cuenta
  • Sin analítica ni anuncios
  • Tokens en el Llavero o el Keystore
