Add GET /pulsar

One route checks your database, cache, workers and providers, and returns a tiny JSON. Guides for 12 frameworks — or write it by hand in any language.

app.get("/pulsar", async (req, res) => {
  if (!authorized(req)) return res.sendStatus(401);
  res.set("Cache-Control", "no-store").json({
    status: "operational",
    components: [{ name: "PostgreSQL",
      state: await checkDatabase(), uptime30d: 0.9999 }],
    checkedAt: new Date().toISOString(),
  });
});

Protect it with one token

A long random PULSAR_TOKEN lives in your server environment and travels only in the Authorization header. Wrong token, no checks, 401.

PULSAR_ENABLED=true
PULSAR_TOKEN=<openssl rand -hex 32>

When it fails, Pulsar says why.

No red dot and a shrug. Every failed check is explained in plain words, and the last known state of each component stays on screen.

Authentication failed
The Pulsar token was rejected by your API.
Request timed out
No complete response from api.example.com within 10 s.
TLS handshake failed
The server certificate for api.example.com could not be verified.
Insecure redirect blocked
The server redirected from HTTPS to plain HTTP. Pulsar never sends your token over plain HTTP after a redirect.
Host not found
DNS lookup for api.example.com failed.
Invalid Pulsar response
Each validation error names the field and what was expected.

Security you don’t have to configure.

The defaults are the safe ones, and none of them can be switched off.

Tokens stay sealed

Stored only in the iOS Keychain or Android Keystore, never shown again, never written to logs, exports or notifications.

TLS always validated

Self-signed or mismatched certificates are rejected. There is no “trust anyway” button.

No token leaks on redirects

HTTPS-to-HTTP redirects are blocked and the token is never forwarded to a different host.

HTTP only where it belongs

Plain HTTP is allowed only for development servers on your local network, and always marked Not Secure.

App Lock

Face ID, fingerprint or your device passcode, after the delay you choose.

Nothing leaves your phone
